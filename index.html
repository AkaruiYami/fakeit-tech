fakeit-tech

You don't need to be a real hacker.
You just need to look like one.

A small Rust CLI tool that generates Hollywood-style "hacker scene" terminal output, complete with flashy progress bars, cascading code, and cinematic effects. Perfect for demos, videos, livestreams, or just impressing your cat.

View on GitHub Quick Start

git clone https://github.com/AkaruiYami/fakeit-tech.git && cd fakeit-tech && cargo run

Features

Modular FakeModules

Each effect is a self-contained module. Run them all in sequence or pick your favorite: AI training, build pipelines, cypher grids, matrix rain, and more.

Loop Mode

Throw --loop on any module and it runs forever.

Extremely Extensible

Drop a new Rust file in src/modules/, implement one trait, register it, and you're done. New effects in minutes.

Cinematic Output

Colored output, animated progress bars, randomized characters.

See It In Action

Each module produces its own unique cinematic effect. Here's a sneak peek.

ai

Blue/green training progress lines that increment to 100%.

build

Full build pipeline simulation: collecting files, random warnings, and a "Build finished successfully!" message.

cypher-square

A mutating grid of randomized characters with error highlights. The Matrix called, and it wants its aesthetic back.

matrix-rain

Classic falling green characters.

Quick Start

01

Clone & Build

git clone https://github.com/AkaruiYami/fakeit-tech.git
cd fakeit-tech
cargo build --release
02

Run the Full Sequence

./target/release/fakeit-tech
03

Or Pick a Module

./target/release/fakeit-tech ai
./target/release/fakeit-tech build
./target/release/fakeit-tech "cypher-square"
./target/release/fakeit-tech hack
04

Loop It Forever

./target/release/fakeit-tech --loop
./target/release/fakeit-tech build --loop
>

Want to see what's available? List all modules with:

./target/release/fakeit-tech --list

Modules

matrix-rain Falling green characters.

Why I Built This

I was bored and wanted to build something that looked cool even if it was ultimately pointless. Partly an excuse to get more comfortable with Rust, partly because I thought hacker terminals in movies looked neat.

That's it. No grand vision. Just a fun weekend project that turned into something I'm mildly proud of.
